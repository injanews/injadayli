# Smart-Fog-Controller 🌫️ 

یک پروژه متن‌باز (Open-Source) برای اتوماسیون و کنترل هوشمند سیستم‌های خنک‌کننده تبخیری (Fog Systems). این اسکریپت بر پایه پایتون نوشته شده و با استفاده از سنسورهای دما و رطوبت (DHT22)، الکتروموتورهای فشار قوی را کنترل می‌کند تا از اشباع رطوبت در فضاهای بسته و گلخانه‌ها جلوگیری شود.

## 📋 منطق پروژه (Logic)
بزرگترین مشکل در راه‌اندازی یک **سیستم مه پاش** صنعتی، تنظیم زمان‌بندی (Timing) روشن و خاموش شدن پمپ است. تایمرهای آنالوگ معمولاً دما و رطوبت لحظه‌ای محیط را در نظر نمی‌گیرند. این کنترلر هوشمند، داده‌های محیطی را هر ۵ ثانیه پایش کرده و بر اساس نمودار سایکرومتریک (Psychrometric Chart)، فرمان قطع و وصل را به رله ارسال می‌کند.

## ⚙️ نیازمندی‌های سخت‌افزاری (Hardware Requirements)
برای اجرای این پروژه، علاوه بر قطعات الکترونیکی، نیازمند یک شبکه هیدرولیکی استاندارد و ضدچکه هستید:

| ردیف | نام قطعه | توضیحات و مشخصات فنی |
|------|-----------|-----------------------|
| ۱ | برد کنترلر | Raspberry Pi 4 یا Arduino Mega 2560 |
| ۲ | ماژول سنسور | سنسور دما و رطوبت دیجیتال DHT22 |
| ۳ | رله قدرتی | رله SSR با توان ۳۰ آمپر (برای پمپ‌های تک‌فاز) |
| ۴ | تجهیزات هیدرولیک | **[خرید مه پاش](https://mahpash-sanaat.com/product-category/%d9%85%d9%87-%d9%be%d8%a7%d8%b4/)** صنعتی (شامل پمپ ایتالیایی ۱۰۰ بار، نازل‌های ضدچکه و فیلترهای پلی‌پروپیلن) از مهپاش صنعت |

> **هشدار ایمنی:** لطفاً از اتصال این کنترلر به پمپ‌های کارواش یا تجهیزات غیراستاندارد خودداری کنید. نوسانات آمپر در پمپ‌های بی‌کیفیت باعث سوختن رله و آسیب به برد اصلی می‌شود. برای قطعات مکانیکی حتماً از برندهای معتبر تأمین شده توسط mahpashsanaat استفاده نمایید.

## 💻 نمونه کد اجرایی (Python Logic Snippet)
کد زیر هسته اصلی تصمیم‌گیری برای روشن کردن پمپ بر اساس متغیرهای اقلیمی است:

```python
import time
import Adafruit_DHT

SENSOR_PIN = 4
TEMP_THRESHOLD = 32.0  # Celsius
HUMIDITY_MAX = 65.0    # Percentage

def check_climate():
    humidity, temperature = Adafruit_DHT.read_retry(Adafruit_DHT.DHT22, SENSOR_PIN)
    if temperature > TEMP_THRESHOLD and humidity < HUMIDITY_MAX:
        activate_pump(duration=20)  # Spray for 20 seconds
    else:
        deactivate_pump()

while True:
    check_climate()
    time.sleep(60) # Wait a minute before next check
